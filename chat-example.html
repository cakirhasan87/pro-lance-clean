Floating Chat Button

The floating chat button appears in the corner of the page. This is the default implementation and requires minimal setup.

Implementation

<!-- Include the chat script in your HTML -->
<script src="js/chat.min.js"></script>

<!-- In your configuration -->
containerSelector: null

Live Example

The floating chat button is visible in the bottom right corner of this page.

Embedded Chat Widget

The chat widget can be embedded directly into a page, rather than floating in the corner.

Implementation

<!-- Create a container for the chat -->
<div id="my-chat-container" class="embedded-chat-container"></div>

<!-- In your configuration -->
containerSelector: '#my-chat-container'

Custom Styled Chat

You can customize the appearance of the chat widget with custom CSS.

Implementation

<!-- In your configuration -->
primaryColor: '#9c27b0',
  
<!-- In your CSS -->
.n8n-chat-widget .n8n-chat-header {
  background-image: linear-gradient(135deg, #9c27b0, #673ab7);
}

.n8n-chat-widget .n8n-chat-button {
  background-image: linear-gradient(135deg, #9c27b0, #673ab7);
  box-shadow: 0 4px 10px rgba(156, 39, 176, 0.3);
}
